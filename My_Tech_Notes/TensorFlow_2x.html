A scalar number is a zeroth order tensor, a vector is a first order tensor, matrix is second order, etc.
TF data types: e.g. tf.float32, tf.float64, int8,16,32,64, tf.uint8, string, bool (27).

Primitive types are constants and variables. Variables are trainable.
Variables have a given shape: they can be assigned to values of same shape. However, rows can be assigned.

  v[1].assign([1.,2.,3.])
Constants are not modified during the training phase.

tf.rank(x) retrieves the rank of x: the dimensionality of the tensor.
Each tensor has the get_shape() method to retrieve the shape.
Variables (33):

  • can be updated by operations
  • hold learned parameters
  • can be stored and restored
Tensors are the intermediate representations of data as it passes through the model.

The tf.function decorator converts a Python function into a function backed by a graph.
If a decorated function calls an undecorated function, the undecorated function becomes part of the graph too.

(35) Constants that are defined outside a decorated python function can print their values inside the function using the python print function.
If a constant is defines inside a decorated function, its value can be printed using the tf2.print() function.

Autograph creates callable graphs from python functions (39). (40) Arithmetic functions in TF2: add(), subtract(), multiply(), tf.math.divide().

Differentiation and TF gradient tape in TF2 (50) During eager execution, the TF2 context manager traces operations for computing gradients.
This context manager has a watch() method to specify a tensor that will be differentiated.
The gradient tape can only compute one gradient (50).

(52) How to calculate the second order derivative using nested gradient tape loops.

Useful TF2 APIs

(64) Note:
  • tf.rank() the number of indexes required to uniquely select an element of the tensor.
    The tensor rank is not the same as the matrix rank.
  • tf.size() returns the number of elements
  • tf.shape() returns the number of elements in each dimension
  • tf.cast() casts a tensor into a target data type
tf.math.divide(x,y): x and y must have the same shape. Returns the element-wise division.
