    Gradient descent is a first order iterative optimization algorithm to find the local minimum of a differentiable function.
    Equation: y = b + wx + epsilon. Epsilon is the error = y - (b+wx).
    w The split between train-validation-test split must be the first thing to do.
    In order to calculate the loss:
    • if we use all data then it is batch gradient descent
    • if we use a datum then it is stochastic gradient descent
    • anything else is mini-batch gradient descent
    MSE is mean squared error
