Ch1:Working with Numbers and Strings

(136) To convert from number to string, use: std::to_string()
(137) To convert from string to number, use: std::ston(), where n stands for: i= integer, l= long, ll= long long, ul= unsigned long, ull= unsigned long long.
These function discard all white characters before a non-whitespace character.
(139) In case the conversion fails, these functions return either: std::invalid_argument or std::out_of_range.

Note that it is possible to use std::string_view instead of strings. They contain a pointer to the underlying string data and the size.

Ch2: Exploring Functions

Defaulted and deleted functions

(231): Special members are: default constructor, copy constructor, move constructor, copy assignment, move assignment, destructor.
  • If a user-defined constructor, or a virtual destructor exists, then the default constructor is not generated by default
  • If a move constructor or move assignment exists, then the copy constructor and copy assignment are not generated by default
  • If a user-defined copy constr, move constr, copy assign, move assign, destructor exists, then the move constr and move assign are not generated

Defaulting and deleting:

  • To default a function, use =default instead of the function body.
  • To delete a function, used =delete instead of the function body. Any function, including non-member fuctions, can be deleted.
Rule of five (234) rule of five: if you define any of the: copy constr, move constr, copy assign, move assign, destructor, then you must define all of them.

Ch3: Preprocessor and compilation

(307) After the arguments for the invocation of a function-like macro have been identified, argument substitution takes place. A parameter in the replacement list, unless preceded by a # or ## preprocessing token or followed by a ## preprocessing token (see below), is replaced by the corresponding argument after all the macros contained therein have been expanded. Before being substituted, each argument's preprocessing tokens are completely macro replaced as if they formed the rest of the preprocessing file; no other preprocessing tokens is available.
