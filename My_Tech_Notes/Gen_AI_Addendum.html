If the model is solving a multi-class classification problem, logits typically become an input to the softmax function. The softmax function then generates a vector of (normalized) probabilities with one value for each possible class.

Pre training models

By using pre-trained models and the magic of transfer learning, the hard work of training an AI model from zero can be bypassed, making it easier and quicker to get the job done. By leveraging the knowledge a model distills from a large dataset, we can reduce the amount of training needed to get a performant model.
Transfer learning: The process where knowledge from a pre-trained model is applied to a new, but related task. Examples of datasets: Common Crawl for NLP, ImageNet for image classigfication, Librispeech: 1000 hours of audiobooks to train TTS systems.
At the end of the training process, using a pre-trained model, there is a new model.
Often the last layer will change and it will be trained from scratch during training with a pre-trained model, because we need a number of output nodel different from the original network.
MobileNet v3 is a model suitable for mobile devices, it can be used as a pre-trained model.
In trasfer learning, we use supervised learning, so images are labelled.
Different example: spam filter. Use DistilBERT as pre-trained model.DistilBERT is a smaller, but effective version of BERT.
