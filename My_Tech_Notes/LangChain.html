.. Concepts

... Chains

Compose modular components into reusable pipelines.
Router chains can decide which tool to use.
Break down a workflow into logical steps.
Chains are stateless.
Callbacks monitor chains.

... Agents

An agent is an autonomous software entity that is capable of taking actions to accomplish goals and tasks.
Agents orchestrate chains, while chains are low-level modules; chains orchestrate modules.
Agents observe the environment, decide which chain to execute, run the chain and repeat.
Agents are stateful. (later, the book says that agents are statelss).

... Tools

Tools are functions that agents call to take real-world actions.
Allow the integration of external services like databases and API(s).

... Memory

Memory: persisting state between executions of agents and chains.
There are purpose-built memory server like: Rememberall and Motorhead that offer conversational contexts.

It is possible to create an API server with langserve. The API has an embedded playground, accessible, for example at:
http://localhost:8000/chain/playground/
