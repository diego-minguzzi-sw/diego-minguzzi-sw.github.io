Fields and variables in Kotlin

lazy initialization

Example: 
  val name by lazy { getName() }
getName() is executed when name is accessed the first time. Lazy initialization can be used only with immutable references (18).

Late initialization

Works with mutable references: 
  lateinit var otherName: String

Functions

(24): in Kotlin it is possible to write functions at package level, or creating a companion object.
There are regular functions and functions defined with the expression syntax. Example:
fun add2( a:Int, b:Int) = a+b
Local functions: (29) functions that are defined within other functions.

Extension functions

(30): Syntax: fun ClassName.method(args...) . Example: 
fun MyClass.retrieveName():String = this.name

lambda functions

(31). (32): when a lambda has a single paramter, it can be omitted, but it is named it.

Nulls in Kotlin

(33) any nullable type is a child of the corresponding nullable type.
Safe call operator (33): 
obj?.method()

Elvis Operator (34): 
obj?.method() ?: alternativeValue

Collections

By default collections are immutable (26).

Packages

In Kotlin, the package does not have to correspond to a directory structure and classes do not have to be in a file with the same name (27).
