. Data Types

Data is immutable in Elixir.

.. Data Types: Atoms

  :anAtom
  :true
  :false
  :ok
  :nil
  AnAtom == Elixir.AnAtom
AnAtom is added implicitly to the module Elixir

.. Data Types: Booleans

Booleans are just atoms that have value true or false.

.. Data Types: Truthiness

nil and false are falsy values, everything else is true.
This property is used with Elixir short-circuit operators.

.. Data Types: Tuples

Untyped structures, or records. Tuples group a small number of elements together.
Immutability: if a tuple is modified, a shallow copy is created and then modified with the new value.
Most of the data is not copied.

.. Data Types: Maps

iex(1)> squares= %{ 1 => 1,
...(1)> 2 => 4,
...(1)> 3 => 9,
...(1)> 4 => 16}
%{1 => 1, 2 => 4, 3 => 9, 4 => 16}

iex(2)> squares[3]
9

iex(3)> Map.get(squares, 5, :not_found)
:not_found

iex(4)> squares= Map.put( squares, 5, 25)
%{1 => 1, 2 => 4, 3 => 9, 4 => 16, 5 => 25}

iex(5)> Map.fetch( squares, 5)
{:ok, 25}

iex(6)> Map.fetch( squares, 7)
:error

.. Data Types: Maps to create structured data

It is stull a map, all Map functions apply, but it can be used to manage strutures. 
iex(10)> bob = %{ :name => "Bob", :age => 25, :works_at => "Initech"}
%{name: "Bob", age: 25, works_at: "Initech"}
iex(11)> bob[:name]
"Bob"

iex(12)> jill = %{ name: "Jill", age: 32, works_at: "Megacorp"}
%{name: "Jill", age: 32, works_at: "Megacorp"}

iex(13)> jill.name
"Jill"

%{ bob | age: 27, works_at: "Initrode" } # Modifies multiple fields of a structure.

.. Data Types: Lists

Lists manage dynamic, variable sized collections of data 
  prime_numbers = [1,3,5,7]

  iex(7)> 3 in prime_numbers
  true

  iex(9)> Enum.at(prime_numbers,2) # Accesses an item at a given index. Traverses the list. O(n)
  5

  iex(11)> prime_numbers= List.replace_at(prime_numbers, 0, 121) # Rebinds to the same variable.
  [121, 3, 5, 7]

  prime_numbers = List.delete_at(prime_numbers,0)


  list = [ head | tail ]
  iex(14)> [ 1 | [ 2 | [ 3 | [] ] ] ]
  [1, 2, 3]

  # Pushes a new element in first position
  list = [ 0 | list ]

. Functions

Conventions:
  • If a function ends with a question mark, it returns true or false
  • If a function ends with an exclamation mark, it may raise a runtime error
The return value of a function is it last expression. 
defmodule Geometry do
  def rectangle_area(a,b) do
    a * b
  end

  def rectangle_area2( a, b), do: a * b

end
Arity a function is identified by its containing module and its arity, the number of its arguments.
Multiple functions with the same name can exist in the same module, as long as the arity is different.
defmodule AModule
  def add( a, a1\\0, a2\\0, a3\\0, a4\\0, a5\\0, a6\\0, a7\\0, a8\\0, a9\\0, a10\\0) do
    a + a1 + a2 + a3 + a4 + a5 + a6 + a7 + a8 + a9 + a10
  end
end
Example of default arguments.

Public and private functions: use def or defp.

. Modules

Module names are camelcase.
Module / submodule names are divided by the dot A file can contain multiple module definitions.
A module can contain multiple functions
Usually a common prefix is added to all modules in a project.

.. Importing Modules

import IO imports a module
alias IO, as: MyIO imports a module with a different name.

.. Module Attributes

  defmodule Circle do
    @pi 3.14159
  end
In the example, the Circle.pi constant exists at compile time. Its references are inlined.
