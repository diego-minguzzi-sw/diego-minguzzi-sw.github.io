Zig Programming

. Comments

There are no multi line comments, only double slash //

. Data types

Data types: u8, i8, u16, i16, u32, i32, u47, i47, u64, i64, f32 and f64. The inclusion of u47 and i47 isn't a test to make sure you're still awake; Zig supports arbitrary bit-width integers.

.{} Creates an anonymous structire literal.

Operators

There are the logical operators and , or .
No ternary operator, but if else is an expression, not a statement, so it can evaluate to a value.

. Functions

There is no function overloading, and no functions with arbitrary number of arguments.
Functions that start with the AT character are builtin functions. They are provided by the compiler.
