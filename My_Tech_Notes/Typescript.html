.. Installed using NPM

  npm install typescript --save-dev
  npm install typescript -g
To install the tool to run Typescript in the command line: 
  npm install -g ts-node
To run the typescript directly,for example to run the file builtin_types.ts: 
  ts-node builtin_types.ts
Type aliases: a type alias is just an alias for another type, it is not a new type.
string can still be used in place of ContactName. 
  type ContactName = string
