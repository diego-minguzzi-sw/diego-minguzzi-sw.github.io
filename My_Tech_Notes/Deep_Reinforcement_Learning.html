.. DRL-Theory. Terms: agent, reward, environment, etc.

(4) In RL, observation is the result of actions. If the agent does nothing, or it always makes the wrong thing, there is no way of collecting better results.
(5) There must be a balance between exploration and exploitation.
Terms:
  • Reward: a scalar value obtained periodically from the environment, it can be positive or negative.
    It is possible that the agent receives zero rewards, except the last one (6).
    Reward is local, it reflects the recent activity of the agent.
    Reward can be found in lots of practical problems, or artificially injected.
  • Agent. The agent makes actions, observations and receives reward:
    it tries to accumulate the largest reward over its sequence of actions.
  • Environment: the agent makes actions on the environment, the agent also receives reward and observations from the environment.
    The environment has a state, which can be observable or hidden
  • Actions: they can be discrete or continuous
  • Observations: information provided by the environment, describing what is going on around the agent
  • Policy: (23) some set of rules that control the agent's behavior

.. DRL-Theory. the Markov Process (MP)

(12) MP is simpler than MDP.
  • States: a set of finite states
  • The system can switch between states with a given law, you cannot influence it
  • Chain: a sequence of states
  • Markov property: the next system state only depends on the current state.
    Suppose that the system state is sunny/rainy.
    Given the current state (e.g. summy), we can say: the next state is 60% sunny and 40% rainy, but it only depends on the current state.
  • There is a transition matrix: the matrix item (i,j) is the probability of switching from the state i into the state j.
Also, Markov implies stationarity (16). Stationarity: in case of MP, it happens when the transition matrix never changes.
(16) In some cases, we have observations instead of probabilities: they are called episodes.
We can estimate the matrix from the observations: we count all the transitions and then we normalize to 1 (one).
The more data we have, the more the resulting table is close to the underlying model.

The concrete observed episodes are sampled from the distribution of the model (16).

(17) The MP model can be extended to include reward.
We can add another matrix, with a reward for every transition from state i to state j. The reward can be also simply a function of the target state.
In that case the function is r=reward(state), otherwise r=reward( src-state, target-state).
We also add a discount factor, called gamma (17) The return at time t:

Gt= sum k=0 ( gamma^k * R[t+k+1] )

Gamma is usually 0.9 or 0.99.
Expected value of a state. We can calculate the mathematical expectation of return from every state:

v(s)= E[G | St = s]

V(s) is the expected value of a given state.

... Adding Actions to the MP

(20) In the simple case, the matrix has N rows and N columns. The i,j item contains the probability of switching from i to j.
Now the matrix has a depth corresponding to the number of possible actions (21).
  • the source state is the height i
  • the target state is the width j
  • the action is the depth k

... Policy

The rules that control the agent behavior.
The probability of executing an action when in a given state (23).

pi(a|s) = P[ At = a | St = s] (23)

If the policy is fixed, then the MDP becomes a Markov reward process.

... DRL-Theory. RL methods: classification

  • Model-free or model based: model-free: the agent does not build a model of the environment.
    Model-based agents are mostly for deterministic environments, like boards games.
  • Value-based or policy-based:
    policy-based methods directly approximate the actions that the agent should carry-out, with a probability distribution over the available actions.
    value-based methods approximate the value of each action and choose that action with the best value
  • On-policy or Off-policy: off-policy is when the agent can learn from historical data

.. Method: The Cross-Entrophy method

(83) Part of the category: model-free, policy-based methods.
Pros: the method is simple, good convergence, for simple environments without complex, multistep policies.

We create a non-linear, trainable function, that maps observations to probability over the actions.

(86) During the agent lifetime, its experience is presented as episodes.
Every episode is a sequence of observations, rewards and performed actions.

... Method: The Cross-Entrophy method. The Steps

Hyper-parameters: the number of episodes N, the reward boundary
  • Play N episodes using the current model and the environment
  • Calculate the total reward on every episode.
  • Throw away the episodes the a reward less than the 50th percentile or 70th percentile
  • Train on the remaining elite episodes, above the reward boundary
  • Repeat

.. Method: Tabular Learning and the Bellman Equation (Q-Learning)

(107) The Value of a state is the expected total reward (optionally discounted) that is obtainable from that state.
The value is calculated with respect to a policy that the agent follows.
Optimal policy: the one that chooses the states with the highest value.

... Tabular Learning and the Bellman Equation (Q-Learning): the Bellmann equation of optimality

  • The agent is in state s0, it has N actions: a1, a2, ..., aN.
  • Each action leads to a state, that has a reward: r1, r2, ..., rN.
  • The value of V0 depends on the next action V0(a=ai)=ri+Vi
  • The best action is ai such that i: max ri+Vi. In case gamma is used, the optimal action a:
    V0= max ra+gamma*Va.
    It must be chosen the action that maximizes: ra + gamma*Va. This is for the deterministic case, where actions are deterministic.(111)
  • In the non deterministic case:
    V0=p1*(r1+gamma*V1)+ p2*(r2+gamma*V2)+ p3*(r3+gamma*V3)
    V0= sum(pi*(gamma*Vi)) This is the value of s0 when there is only one action, but the outcome it a distribution of probabilities.
  • Using Bellman on the non deterministic case:
    Choose the action :
    V0= max a: sum(p(a,0,s)*(ri+ gamma*Vi)) (112)
    p(a,0,s): the probability is issuing the action a and switching from the state 0 to the state s.

Other quantities:

  • V(s): the value of a state, given a policy
  • Q(s,a): the total reward we get from choosing the action a when in state s
  • We try to evaluate Q(s,a) for every state and action. Q(s,a) takes into accout:
    • Immediate reward
    • Probabilities of the next states, following the action a
    • Discounted value of every next state
    • It is also possible to define V(s)= max(a:Q(s,a)). The value of s is defined as the Q of the best action a in the state s.
    • Q(s,a)= r(s,a)+ gamma*max(a',Q(s',a'))
Example: initial state s0, possible next states: s1, s2, s3, s4.
Every action has a probability and a
  • Q(s0,up)= 0.33*r1 + 0.33*r2+0.33r4
  • Q(s0,up)= 0.33*r1 + 0.33*r2+0.33r4
So, Q is used in practice. On a given state, calculate Q for all possible actions and choose the action with the highest Q (115).
The agent must also know the probabilities for each action-state pair.
Given that gamma < 0, we can stop after 50 iterations and still get a precise value.
We have the history of the interaction of the agent with the environment. The data structures are (117):
  • Reward table: a map from : source state, action, target state , to reward.
  • Transition table: for each (action, state), keeps track of the each actual target state and a counter.
    For each couple there is a dictionary that maps: state to counter.
  • Value table: maps each state to its value

... PyTorch Introduction

(49) Tensor: multidimensional array. 
  a= torch.FloatTensor(3,2) # 3 rows, 2 columns.
  a.zero_() # In place operation.
(53) Most operations are contained in the torch package and the tensor class.
(55) All gradients are calculated, backpropagated and applied to the network. To do that, the NN architecture must be defined in terms of the DL library.
Different approaches in calculating the gradients: (55)
  • Static graph: all calculations are defined and optimized in advance, it is no more possible to change them
  • Dynamic graph: execute the operations, the library records the operations. Then it unrolls the operations and accumulate the gradients of the network parameters.
    This method is used by PyTorch.
PyTorch tensors have built-in gradient calculation (56).
Every tensor has some characteristic:
  • grad: every tensor has a tensor of same shape with its gradient
  • is_leaf: true if the tensor was constructed by the user, false if it is the result of a transformation
  • required_grad: if this tensor require the gradient to be calculated. By default false.
Example of layer construction: nn.Linear(2,5) it means 2 inputs, 5 outputs (60).
The nn.Module is the superclass of all NN building blocks.

... PyTorch: Example of Custom Module

import torch.nn as nn

class MyModule(nn.Module):
    def __init__(self, numInputs: int, numClasses: int, dropoutProb=0.3):
        super(MyModule, self).__init__()
        self._pipe= nn.Sequential( 
                        nn.Linear(numInputs,5),
                        # [...]
                        nn.Linear(20,numClasses),
                        nn.Dropout(p=dropoutProb),
                        nn.Softmax(dim=1))
    # This method must exist.    
    def forward(self, x):
        return self._pipe(x)
