(16) Pipeline: a suite of plug-ins that support the creation of continuous delivery pipelines (16).
Extensible set of tools for modeling delivery pipelines as code, via a DSL. Terms:

  • agent: pipeline executor
  • stage: one or more stages of the pipeline: Build, Test, Deploy
  • step: a single command executed by the Pipeline
  • node: pipeline work is done in the context of nodes.
    As soon as the executor is free on a node, the steps will run.
    (25) node: an executor and workspace in the Jenkins environment.
