Variadic function templates

Function templates with a variable number of arguments are called variadic function templates (163).
  /* Overload that ends compile-time recursion.*/
  template <typename T>
  T myAdd(T value)
  {
    return value;
  }

  /* typename... Ts   is a template parameter pack, it indicates a variable number of arguments.
   * Ts... rest   is a function parameter pack. 
   * The compiler replaces the parameter pack with the elements, in their order.*/
  template <typename T, typename... Ts>
  T myAdd(T head, Ts... rest)
  {
    return head + myAdd(rest...);
  }

Defaulted and deleted functions

(144) Special member functions are (the big five):
  • default constructor
  • destructor
  • copy constructor
  • move constructor
  • copy assignment
  • move assignment
Only special member functions can be defaulted (144).
On the other hand, any function can be deleted (144).
  • In case a user defined constructor exists, the compiler does not generate any default constructor
  • If a virtual destructor exists, the compiler does not generate any destructor
  • If a move constructor or move assignment exists, the compiler does not generate any copy constructor or copy assignment
  • If a move or copy, either constructor or assignment exist, no move constructor or assignment is generated
Rule of Five: if you define any copy constr, move constr, copy assign, move assign, destructor, then you must explicitly define or default, or delete all of them.
