(119) Modules:
A module is a typescript class. It contains a decorator with the following properties:
  • declarations
  • imports
  • exports: artifacts that are listed among the declarations, and that other modules can use.
  • providers: services that the module provides

Suppose that a module is called heroes
. To generate the component heroList, part of heroes: 
  ng generate component heroes/heroList --module=heroes
So:
  • A module is added with ng generate
  • One or more components are added to the module
  • The module must list the exported components in the exports list
  • The client module must the import the modules that it uses. 
        import { HeroesModule } from './heroes/heroes.module';

    @NgModule({
      declarations: [
        AppComponent,
        HeroComponent
      ],
      imports: [
        BrowserModule,
        HeroesModule
      ],
      providers: [],
      bootstrap: [AppComponent]
    })
  • Root module: the main module, it is called AppModule
  • Feature Modules: each of them implements a specific functionality
  • Core module: application-wide artifacts that do not fit anywhere else, e.g the top bar, footer bar, spinner, and services like the logging or the local cache service.
    This module is loaded only once in AppModule. (i.e. the Root module)
  • Shared Module: it contains components, directives, and pipes that can be used in feature modules.
We can distinghuish how Angular loads them:
  • Eager loaded: loaded when the application starts
  • Lazily loaded modules
