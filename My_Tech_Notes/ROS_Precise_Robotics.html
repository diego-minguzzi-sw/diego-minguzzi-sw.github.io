ROS Control: a set of packages

ros_control: A set of packages that include controller interfaces, controller managers, transmissions and hardware_interfaces.

  • the Controller Manager can list, load, unload, switch controller.
  • according to the picture, the controller manager has multiple controllers, running at the same time
  • a controller receives the set-point from the ROS interface, depending on the type of control:
    • joint trajectory
    • joint position
    • joint velocity
  • the controller compares the set-point with the joint state, and issues the next command at the Joint Command Interface
  • Controller plug-ins, some examples are in the directory ros_controllers/position_controllers/include/position_controllers/, for example joint_position_controller.h
    In our case, JointGroupPositionController
    • param type Must be "JointGroupPositionController"
    • param joints List of names of the joints to control
    • subscribes to: command (std_msgs::Float64MultiArray): the joint positions to apply

Precise TCP/IP command server (TCS)

The TCS runs on the robot, receives command requests and sends back responses.
Listens on the port 10100.

Commands are not case sensitive.

  • The same controller can command multiple robots.
  • The TCS can store up to 20, 1-indexed positions, they can be cartesian or joint locations. A location is called station
  • The TCS can store up to 20, 1-indexed profiles, a profile is speed, accel, etc.
  • Motion commands: move, move one axis, wait for end-of-motion, zero torque (enable/disable).
