. Intro

From Getting started
Cloud essentials
Cloud computing is the on-demand delivery of computing resources through a platform through the internet with pay-as-you-go pricing. Service models:
  • IaaS: access to networking, computers (virtual or dedicated HW), data storage
  • PaaS: you do no manage the infrastructure, you focus on development and management of the applications
  • Saas: provides a complete product managed by the service provider, for example web-based email
The application can be deployed in multiple locations. Region is a physical location in the world where AWS has multiple Availability Zones. Availability Zones are one or more discrete data centers, each housed in a separate facility.

Developer tools:

  • AWS Management Console
  • AWS CLI. There is also AWS CloudShell: browser based shell with command line access to resources.
  • SDK(s) allows you to interact with the AWS API programmatically
IaaC Infrastructure as a Code AWS provides services that enable the creation, deployment, and maintenance of infrastructure in a programmatic way.
