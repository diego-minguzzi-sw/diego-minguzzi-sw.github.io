Scalable and reliable systems that constantly provide a service without downtime (1). A platform that provides support for: Concurrency, scalability, fault-tolerance, distribution, high-availability.
High availability>
  • Concurrency: Erlang is a concurrency-oriented language. The basic concurrency primitive is the Erlang process (4).
    The Erlang VM (BEAM) schedules and runs processes to the available CPU(s). Erlang processes are isolated from each other. A process crash does not crash the application.
  • Fault tolerance
  • Scalability: processes communicate via asynch messages
  • Distribution: communication is the same regardless of whether the processes are local or remote
  • Responsiveness: the runtime improves the responsivness. The scheduler is preempitive
  • Live Update: upgrade the system without stopping it
Erlang: language, VM, framework, tools.
Elixir macro: code that runs at compile time (11). (17). Variable names start with an underscore or lowercase character. The prevalent convention is lowercase letters and underscores.
Modules are like namespaces (20), a module must be defined in a single file.
A file can contain multiple module definitions (21).
Module names are written in CamelCase The dot can be used to organize modules in a hierarchy: Geometry.Rectangle Geometry.Circle
The dot character is only a convenience. The language does not dictate that.
Functions are always part of a module.(21): the name starts with an lower case character. Conventions:
  • If a function name terminates with a exclamation mark, it may raise a runtime error.
  • If a function name terminates with a question mark, it is because it returns a true or false.
These are conventions.

Pattern Matching

In an assignment, on the left side a pattern, on the right an expression called term(72) (64).
A variable always match the right side, there is a bound between the variable and the result of the expression.
Constants can be on the left side of the assignment, in the pattern side (65).
    iex(11)> person= {:person,"Bob",26}
    {:person, "Bob", 26}
    iex(12)> {:person,name,age}= person
    {:person, "Bob", 26}
    iex(13)> age                       
    26

(66)By using contants in a pattern, you tighten the match, making sure some part of the right side has a specific value.

The underscore _ is the anonymous variable (66)
Patterns can be nested.

Pattern matching works also when a function is executed. The provided arguments are matched against the patterns of the function- Multiclause functions (e.g. function overloading) (73). Multiclause functions are a way of doing branching (79). 

  defmodule Geometry do      
    def area({:rectangle, w, h}), do: w*h
    
    def area({:square, s}), do: s*s
    
    def area({:circle, r}), do: r*r*3.14
    
    # Default case: a variable matches any argument.
    def area(unknown), do: {:error, {:unknownShape, unknown}}
    
    def perimeter(:circle, r), do: 2*r*3.14
  
    def perimeter(:square, a), do: 4*a      
  end    
  
  defmodule ListUtils do
    def isListEmpty?([]), do: true    
    def isListEmpty?([_|_]), do: :false
    
    def sum([]), do: 0  
    def sum([head | tail]) when is_number(head), do: head + sum(tail)
  end
Note 1: function clauses are matched top to bottom, until a match is found. Note: the capture operator captures all function clauses (74).
