JS Primer, part 2

All JS object inherit from a prototype object: the root of the hierarchy is Object.

Example of a JS class implementing an iterator. 

class GiftPack {
    constructor( name, prod, prod2, prod3) {
        this.name= name;
        this.prod= prod;
        this.prod2= prod2;
        this.prod3= prod3;
    }

    *[Symbol.iterator](){
        yield this.prod;
        yield this.prod2;
        yield this.prod3;
    }

    getTotalPrice(){
        return [...this].reduce( (total,p) => total+ p.price, 0 );
    }
}

Type Unions example:

(158) you can only use the properties and methods defined by all the types of the union. That is, you can use only the properties and methods that exist in all the types of the union.

Type assertions : they are type casts

let myVar = myFunction( aValue ) as number;
No type conversion is performed. The compiler just treats the value with the asserted type. The asserted type must be one of the types of the union.

The never type: when a variable is assigned the never type, its value can no more be accessed (164). It means that all other conditions are already tested.

the unknown type: (164) a variable of unknown type can be assigned to:

  • any
  • unknown
  • another type, using the type assertion (cast)
Nullable types null and undefined are legal for all types (166). null and undefined are values of all data types, so they can be assigned to them.

Defining Functions

A function with an optional parameter can be defined as: 
function calculatePrice( amount: number, discount?: number ) :number {
    [...]
}
A function parameter can be gived a default value: 
function calculatePrice( amount: number, discount=0 ) :number {
    [...]
}
Note: default parameters and optional parameters must be defined after required parameters.
Example of rest parameter: 
function functionWithRestParameter( amount, discount=0, ...extraFees) :number {
  [...]
}
(180) The rest parameter is prefixed by the ellipsis.
It is possible to annotate function arguments with data types, for example: 
function functionWithRestParameter( amount: number, discount:number=0, ...extraFees: number[]) :number

(182) null and undefined can be used as values for all types. (184) Using the noImplicitReturns: true flag in the tsconfig.json file, means that the compiler will check that all exit paths from a function have a return statement.

The return type can be annotated, a function can return a void type.
(187) type overload: a function have only one implmentation, but it is possible to express the relationship between argument types and returned type.

Angular make use of decorators.
There are two compilation stages in Angular: the first is the tsc. It terminates with : 

Date: 2020-10-17T13:42:44.133Z - Hash: 39ea808b9f2703a11a0f - Time: 196ms
5 unchanged chunks
i ｢wdm｣: Compiled successfully.
The second compilation stage happens when the bundle is received by the browser:
  • HTML files are extracted from the bundle
  • HTML files are compiled, the directives are translated into javascript that the browser can execute
This two phase compilation can slow the application the first time it is executed.
The alternative is ahead-of-time (AOT) compilation: all the stuff is compiled in advance and included in the bundle.
Dependency injection: a class depend on an abstract class, that is declared in the constructor. In the costructor the injected class object is declared as a member, that is then used in the body of the class.

(431) With web application frameworks, updates are handled automatically.
Angular uses RxJS to manage updates.
The Observable class is a replacement of the JS Promise.

Angular splits the generation of HTML content into:

  • A typescipt class that has the Component decorator:
  • An HTML template that is annotated with directives.
The role of the class is included in the filename.
The Component decorator configures the component: 
@Component({
  selector: "product-item",
  templateUrl: "./productItem.component.html"
})
The selector specifies the selector that Angular will use to apply the component to the application HTML.
The templateUrl specifies the HTML template.

The Input decorator allows a component to receive input as HTML attributes.
The Output decorator specifies the output as an event.

Angular templates uses double curly braces to include results of Typescript expressions: 

{{ product.name }}
Events are specified using parenthesis around the event name: 
< button class="btn btn-success btn-sm float-right" (click)="handleAddToCart()" >Add To Cart < / button >

The Application module: app.module.ts configures all modules and components.
