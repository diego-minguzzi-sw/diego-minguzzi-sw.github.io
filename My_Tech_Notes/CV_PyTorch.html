Chp.2 PyTorch Basics

define-by-run mode: computations are executed immediately.
Whereas, in the define-and-run paradigm, first the computational graph is constructed, then data is run through it.
In the define-and-run, it is not possible to modify the graph dynamically.

Broadcasting

  • Align dimensions from the right
  • For each dimensions, two sizes are compatible if: they are equal, or one of them is one so it will be stretched.
Broadcsting is executed before the operation. For example, addition in PyTorch can be executed if the tensors have the same shape.
Note that some operations create a view of the underlying storage.
The operations: add(), sub(), mul(), div() are performed element-wise.

In squeeze and unsqueeze, the returned tensor shares the same underlying data with this tensor.
Given that in PyTorch computational graphs are dynamic, they are rebuild from scratch every time the .backward() function is called.
Gradients consume memory. Once they have been used, it is better to zero them out.
