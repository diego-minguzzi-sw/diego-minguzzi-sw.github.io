Class Libraries

A class can have
  • Methods: Plain, Constructor, Property, Indexer, Operator.
    Properties are the preferred way of storing fields, unless the memory address of the field must be exposed.
  • Fields (144):
    • Plain field
    • Constant: the data never changes: the compiler inserts the constant in every place where it is referred. When a constant is changed, the code must be rebuild.
    • Read Only: the data can be changed when the object is instantiated.
    • Event: the data references one or more methods that are called when the event is raised.
